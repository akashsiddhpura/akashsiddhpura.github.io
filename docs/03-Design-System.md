# Overview

This document defines the complete visual language for Portfolio v2.

The goal is to create a premium, modern, and timeless design system that reflects craftsmanship, engineering excellence, and thoughtful product design.

The website should never feel like a template.

Every component should feel intentional.

This document acts as the single source of truth for all UI decisions.

---

# Visual Principles

## Simplicity First

Remove unnecessary elements.

Every visual element should improve communication.

---

## Spacious Layout

Whitespace is part of the design.

Never crowd content.

Give every component room to breathe.

---

## Consistency

The same spacing, radius, shadows, typography, and animations should be used throughout the website.

Consistency creates trust.

---

## Soft Contrast

Avoid harsh black and white.

Prefer subtle contrast.

Use depth through layers instead of borders.

---

## Motion With Purpose

Animations should enhance usability.

Never distract from content.

# Motion Language

Motion should feel:

Fluid

Organic

Elegant

Predictable

Slow enough to appreciate

Fast enough to remain responsive

Avoid abrupt transitions.

---

# Component Rules

Every component must:

Have a clear purpose

Support accessibility

Support responsiveness

Use consistent spacing

Support dark theme

Be reusable

Avoid unnecessary complexity

---

# Design Checklist

Before approving any screen, verify:

✓ Does it feel premium?

✓ Is there enough whitespace?

✓ Is the hierarchy obvious?

✓ Are animations subtle?

✓ Is typography readable?

✓ Does every component have purpose?

✓ Does it communicate craftsmanship?

✓ Would this look at home alongside Apple, Linear, or Vercel?

If the answer to any question is "No", refine the design.

---

# Guiding Principle

The design should never try to impress through excess.

It should earn respect through clarity, precision, consistency, and thoughtful execution.

The interface should quietly communicate that the same level of care will be applied to the products Aakash builds.
