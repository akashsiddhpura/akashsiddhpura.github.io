# Overview

The Layout System defines the structural foundation of the portfolio.

Rather than designing each section independently, every page should follow a consistent layout language built around spacing, rhythm, grids, alignment, and visual hierarchy.

The objective is to create a portfolio that feels cohesive, premium, and carefully engineered.

---

# Layout Philosophy

The layout should disappear.

Visitors should focus on the content—not the layout itself.

Every section should feel balanced, spacious, and intentional.

Whitespace is not empty space.

Whitespace is a design element.

---

# Core Principles

Every layout should be:

✓ Clean

✓ Balanced

✓ Predictable

✓ Spacious

✓ Easy to scan

✓ Responsive

Never:

✗ Crowded

✗ Misaligned

✗ Uneven

✗ Inconsistent

# Alignment

Default

Left Aligned

Centered layouts should be used sparingly.

Center alignment is reserved for:

- Hero
- Empty States
- Contact Success

Everything else should prioritize readability.

6. CTA (Optional)

# Visual Balance

Every section should contain a balance between:

Text

Visual

Whitespace

---

# Image Placement

Images should support content—not compete with it.

Preferred positions:

Right Side

Top

Background Accent

Avoid placing images between paragraphs.

---

# Sticky Elements

Allowed

Navigation

Section Progress

Project TOC (Case Study)

---

# Empty Space

Whitespace is intentional.

Never fill empty space simply because it exists.

Space creates elegance.

---

# Scanning Pattern

Design for F-shaped reading patterns.

Users should understand each section within a few seconds.

Use:

- Short paragraphs
- Bullet points
- Cards
- Highlights
- Visual separators

---

# Responsive Behaviour

Desktop

Content-rich

Tablet

Simplified

Mobile

Focused

Do not simply shrink the desktop layout.

Rebuild layouts for smaller screens when necessary.

---

# Accessibility

Maintain:

- Clear reading order
- Logical tab order
- Adequate spacing
- Large touch targets
- Consistent navigation

Layout should support accessibility by default.

---

# Performance

Avoid layouts that trigger excessive reflows.

Prefer:

Flexbox

CSS Grid

Transform animations

Avoid:

Absolute positioning unless necessary.

---

# Future Scalability

The layout system should easily support future pages.

Examples:

- Blog
- Labs
- Open Source
- Speaking
- Articles
- Notes

Every new page should inherit the same structural language.

---

# Success Criteria

Visitors should feel:

✓ Calm

# Final Principle

A great layout is invisible.

It quietly guides visitors through the experience without demanding attention.

The structure should feel so natural that users focus entirely on the story, the products, and the engineering behind them.

Every layout decision should support clarity, trust, and craftsmanship.
