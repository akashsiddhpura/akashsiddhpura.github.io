# Overview

The Hero is the most important section of the portfolio.

Visitors decide within the first few seconds whether they want to continue exploring.

The Hero should immediately communicate professionalism, engineering excellence, and product thinking without relying on flashy animations or exaggerated claims.

It should create trust before asking for attention.

---

# Purpose

The Hero exists to answer four questions immediately:

1. Who is Aakash?
2. What does he build?
3. Why is he different?
4. Why should I keep scrolling?

If these questions are not answered within the first screen, the Hero has failed.

---

# Business Goal

The Hero should position Aakash as someone capable of building production-grade software for startups and international teams.

It should encourage visitors to:

- Continue exploring
- View projects
- Download resume
- Make contact

---

# Visitor Emotion

The Hero should make visitors feel:

✓ Curious

✓ Confident

✓ Interested

✓ Impressed

Never:

✗ Overwhelmed

✗ Confused

✗ Distracted

✗ Sold to

---

5–8 seconds

Visitors should understand the main message even if they never scroll.

# Scroll Behaviour

As the user scrolls:

Hero content moves slightly upward.

Background glow softens.

Device mockup scales subtly.

Text remains readable.

Avoid dramatic parallax.

# Accessibility

Heading should be H1.

Buttons should have descriptive labels.

Animations should respect Reduced Motion.

Text contrast should exceed WCAG AA.

---

# Performance

Hero assets should load first.

Use:

- Optimized images
- Next.js Image
- Lazy load secondary visuals
- GPU accelerated animations

Avoid heavy videos on initial load.

---

# Responsive Behaviour

Desktop

Two-column layout.

Tablet

Text above.

Device below.

Mobile

Single-column layout.

Large heading.

Buttons stacked.

Trust indicators become horizontal scroll or wrapped grid.

The Hero should still feel premium on smaller screens.

---

# Success Criteria

Within five seconds visitors should know:

✓ Who I am

✓ What I build

✓ Why I stand out

✓ Where to go next

The Hero should create enough confidence that visitors naturally continue scrolling.

---

# Final Principle

The Hero should not try to impress through complexity.

It should quietly communicate confidence through clarity, thoughtful design, and polished execution.

A great Hero doesn't ask visitors to believe you are a great engineer.

It makes them feel it.
