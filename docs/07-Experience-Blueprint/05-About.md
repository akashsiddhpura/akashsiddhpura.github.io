# Overview

The About section is the first opportunity to build a personal connection with visitors.

Unlike the Hero, which focuses on capability, the About section explains the person behind the engineer.

It should communicate curiosity, passion, values, and product mindset without becoming autobiographical.

The goal is not to tell my entire story.

The goal is to explain why I build software the way I do.

---

# Section Purpose

This section exists to answer:

- Who is Aakash?
- Why did he choose software engineering?
- What motivates him?
- How does he approach product development?
- Why does he care so much about quality?

---

# Business Goal

Build a personal connection.

Increase trust.

Transition visitors from "This engineer looks skilled."

to

"I'd enjoy working with this person."

---

# Visitor Emotion

Visitors should feel:

✓ Connected

✓ Inspired

✓ Curious

✓ Confident

Never:

✗ Bored

✗ Overwhelmed

✗ Like they're reading a resume

# Personal Story

Maximum

3 paragraphs.

The story should communicate:

As a child, I was always curious about technology.

I wanted to understand how software worked, not just how to use it.

That curiosity eventually became a career in software engineering.

Today, I enjoy building products that solve meaningful problems and create experiences people genuinely enjoy using.

For me, software is more than writing code.

It is understanding people, solving problems, and transforming ideas into products that deliver real value.

# Responsive Behaviour

Desktop

Two-column layout.

Tablet

Portrait above story.

Mobile

Single-column layout.

Portrait becomes smaller.

Content remains readable without excessive scrolling.

---

# Success Criteria

Visitors should leave this section thinking:

✓ He genuinely enjoys building products.

✓ He understands users, not just code.

✓ He values quality.

✓ He would be a great teammate.

---

# Final Principle

The About section should never feel like self-promotion.

It should feel like an honest conversation.

Rather than listing achievements, it should explain the mindset that drives every product I build.

Visitors should remember the person behind the engineer—not just the technologies listed on the page.
