# Design Notes

Display achievements using premium metric cards.

Organize into clear categories.

Prioritize outcomes over technology.

Avoid overwhelming visitors with too many numbers.

Large typography should emphasize key metrics.

---

# Animation Notes

Counters animate once when entering the viewport.

Category cards reveal with staggered transitions.

Hover interactions should provide subtle depth without distraction.

---

# Accessibility

Ensure animated counters remain understandable without animation.

Maintain high contrast.

Support keyboard navigation.

Readable typography at all screen sizes.
