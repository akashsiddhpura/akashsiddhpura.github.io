# PROJECT 01

SULOK

Community Platform

Senior Flutter Engineer

###############################################################################

## Overview

SULOK is a modern social community platform designed to connect users through discussions, communities, events, messaging, and rich media sharing.

As the lead Flutter engineer, I focused on building scalable architecture, high-performance feeds, intelligent caching, and production-grade user experiences.

---

## My Role

• Software Architecture

• Feed System

• Real-time Messaging

• Media Upload Pipeline

• Performance Optimization

• Payment Integration

• UI/UX Engineering

---

## Engineering Challenges

Building a social feed that felt as smooth as premium social platforms while supporting:

• Images

• Videos

• Rich Text

• Infinite Pagination

• Offline Caching

• Live Updates

• Pull to Refresh

• Optimistic Updates

One of the biggest challenges was synchronizing cached content with newly fetched API data without causing UI blinking, duplicate posts, or scroll position changes.

---

## Solution

Designed an intelligent merge strategy that:

• Preserved scroll position

• Updated only modified posts

• Eliminated UI flickering

• Reduced unnecessary rebuilds

• Improved perceived loading speed

Implemented advanced media caching to ensure videos and images loaded almost instantly during repeated viewing.

---

## Business Impact

• Premium scrolling experience

• Faster media loading

• Reduced waiting time

• Improved feed responsiveness

• Better user engagement

• Scalable architecture for future growth

---

## Technologies

Flutter

BLoC

REST API

AWS S3

WebSocket

Caching

Firebase

---

## Key Takeaway

Great social experiences are built through hundreds of small engineering optimizations that users never notice—but always feel.
