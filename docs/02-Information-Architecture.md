# Overview

This document defines the complete structure, navigation, and user journey for Portfolio v2.

The objective is to create a storytelling experience rather than a traditional portfolio.

Every section should naturally lead visitors to the next section while building trust and demonstrating engineering capability.

The website should feel like an interactive product experience.

---

Navigation Behavior:

# Information Architecture Principles

Every section must answer one question.

Hero

Who is this?

Trust

Why should I trust them?

About

What do they believe?

Experience

Have they done this before?

Projects

Can they solve difficult problems?

Skills

How do they solve them?

Achievements

Did their work make an impact?

Contact

How can I work with them?

---

# Guiding Principle

The website should never feel like scrolling through a resume.

Instead, visitors should feel like they are exploring the journey of a software engineer who builds products with craftsmanship, technical excellence, and attention to detail.

Every scroll should increase confidence.

Every interaction should reinforce quality.
