# AI Development Rules

This document defines the permanent rules for every AI agent working on this project.

---

## Source of Truth

Always follow the documentation inside the `/docs` folder.

Never overwrite documented decisions without approval.

---

## Quality First

Prefer quality over speed.

Never generate template-like UI.

Every component should feel handcrafted.

---

## Code Standards

- TypeScript only.
- Reusable components.
- Strong typing.
- Clean architecture.
- Feature-first structure.
- Server Components by default.
- Client Components only when required.

---

## UI

Premium.

Minimal.

Elegant.

Engineering focused.

Avoid flashy effects.

Avoid unnecessary gradients.

Avoid portfolio clichés.

---

## Animations

Every animation must have a purpose.

Maintain 60 FPS.

Respect Reduced Motion.

Avoid over-animation.

---

## Performance

Target:

95–100 Lighthouse

Never sacrifice performance for visual effects.

---

## Accessibility

Keyboard friendly.

Semantic HTML.

Proper focus states.

Screen reader support.

---

## Responsive

Desktop first quality.

Mobile first implementation.

Every screen must feel intentionally designed.

---

## Development Workflow

Before implementing a section:

1. Understand documentation.
2. Design.
3. Implement.
4. Optimize.
5. Test responsiveness.
6. Continue.

Never skip steps.

---

## Final Principle

This portfolio should feel like a premium software product rather than a personal website.

Every decision should reinforce craftsmanship.
